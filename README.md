# HomeCraftLink Tools

Tools, examples and documentation for [HomeCraftLink](https://homecraftlink.com/).

## About

HomeCraftLink helps you explore websites, collect images, and extract text for reading aloud or translation.

- **Gate 1:** Collect links and review website details.
- **Gate 2:** Collect, preview and export images.
- **Gate 3:** Extract text, read it aloud and translate passages.
- **HTML Editor:** Work with page source and the current DOM.

## Repository status

The first demo is available: [HomeCraftLink Table Demo](table-demo/README.md), with synthetic sample data, setup instructions and validation notes. More tools and individual usage instructions will be added gradually.

## Working with live content

Results depend on the source page and the content currently loaded. They may differ from examples, include unexpected items, or omit content that is unavailable to collect.
